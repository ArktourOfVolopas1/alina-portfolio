05 / SELECTED WORKS

Проекты.

Проекты, в которых я применяю изученные технологии и развиваю навыки backend-разработки.

PROJECT_001 РЕАЛИЗОВАН

SpareParts Manager

REST API для учёта запасных частей сельскохозяйственной техники. Приложение поддерживает создание, просмотр, изменение и удаление записей, поиск по артикулу и названию, фильтрацию по категории, валидацию входных данных и обработку ошибок.

Технологии: Java 21, Spring Boot, Spring Web MVC, Spring Data JPA, Hibernate, PostgreSQL, Maven, Jakarta Bean Validation, JUnit, Mockito, MockMvc.

JAVA · SPRING BOOT · REST API · POSTGRESQL
